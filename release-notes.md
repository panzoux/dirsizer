## DirSizer v0.3.0

- Added logical and NTFS allocated size reporting with `--allocated`.
- Separated directory and file results in table output.
- Added NTFS metadata labels and clearer unresolved-record paths.
- Improved MFT progress updates and directory aggregation performance.
- Added filesystem-specific errors for non-NTFS volumes.

This release contains the self-contained NativeAOT `win-x64` executable.
